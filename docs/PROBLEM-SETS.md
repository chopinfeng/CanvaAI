# 题库与转换核对

## 题目来源

**题库全部为本项目自编**，用于演示和回归测试，不取自任何教辅或试卷汇编。

用的都是教科书里人人都在用的经典构型（矩形折叠、等腰三角形、平行截线、
垂径定理、二次函数……），数值和问法是自己拟的，每一步答案都在
`apps/server/src/__tests__/figures.test.ts` 里按题给条件验算过。

覆盖 20 道题、12 个考点、三档难度。

## 为什么"原图 + 转换结果"并排

题目从纸质试卷进画布，中间隔着一次转录。**转录对不对，只能靠对照原件判断**——
所以每道题左边放原图，右边放转换后的画板内容。

⚠️ 当前题库是自编的，"原图"由 `make-mock-scans.ts` 从同一份数据渲染而来
（衬线字体 + 纸色背景，模拟纸质观感）。**因此左右同源，此时的对照只是流水线的
冒烟测试，不构成对转录准确性的独立校验。** 真要校验转录，需换成真实扫描件，
流程见下面「导入真实试卷」。

## 用法

```bash
cd apps/server && npx tsx scripts/make-mock-scans.ts
```

## 转换到什么程度

| 部分 | 覆盖 | 说明 |
|---|---|---|
| 题干文字 | 20/20 | 条件 + 各小问要求 |
| 已知量结构化 | 14/20 | `known` 字段，Agent 可直接查 |
| 矢量化图形 | 12/20 | 见下面的取舍标准 |
| 参考答案 | 20/20 | `answer` 字段，仅供测试断言；辅导模式不展示 |
| 原图 | 20/20 | 全部保留 |

## 矢量化的取舍标准

**只有坐标能由题给条件精确算出来的，才矢量化。**

理由不是省事：Agent 会用 `canvas_measure` 去量图上的线段和角度，然后拿量出来的数推理。
凭感觉摆出来的图，量出来的每个数都是错的——**那比没有图更糟**。

按这个标准，20 道里 12 道能画、8 道不能：

| 不画 | 原因 |
|---|---|
| G13 | P、Q 的位置随 t 变化，画出来等于替读者选定一个 t |
| G14 | 两种对应关系对应两个不同的 Q，画其一会暗示答案唯一 |
| G15 | 切点位置取决于 P 的方向，题目未给定 |
| G16 / G17 / G18 | 概率、应用题、统计题本就没有几何图形 |
| G19 | 旋转角 α 是自由变量，选定一个角等于回答了第 (2) 问 |
| G20 | 只给了距离关系，画出来会把"作对称点"这一步提前暴露 |

这些原因也写在画布上（`figureNote`），免得看的人以为是漏了。

### 已矢量化的 12 道

坐标推导写在 `scripts/figures.ts` 的注释里，并在测试里按原题条件逐条复验——
给定的长度、角度、平行、共线、中点关系，一条都不能对不上。例如：

- **G1** B 关于折痕 AE 的对称点精确落在 F(12,5)，EF=EB=13/5（用 13-5-12 勾股数保证每步有理）
- **G5** AD=BE=7、∠BFD=60°，且这两条对 AE 的任何取值都成立
- **G2 / G3 / G4 / G7 / G10 / G12** 各自小问的答案都能从图上量出来
- **G11** 采样点逐点验过确实落在 y=x²−2x−3 上

### 一个副作用

图按标准答案的位置画出来，意味着 Agent 量一下就能得到待求量。
辅导模式因此加了硬约束：测量只能用来检验学生自己算的结果、
或制造让他自己发现矛盾的事实，**量出来的答案不准说**。见 `TUTOR_ADDENDUM`。

## 图片资源

内容哈希命名（`as_<sha256前24位>.<ext>`），所以：

- 同一张图重复上传只占一份
- **重新上传能得到完全相同的 id** —— 资源丢了重灌一遍，画布里的引用不会断

存放在 `<仓库根>/data/assets/`，通过 `GET /assets/:id` 提供（HEAD 同样支持），长缓存。
id 有严格格式校验，挡掉路径穿越。

## 加自己的题

在 `apps/server/scripts/problems.ts` 里加一条 `Problem`：写题干，
图形能由条件唯一确定就给 `figure`，不能就留空并在 `figureNote` 里写明原因。
然后重跑 `make-mock-scans.ts` 和 `seed-exam-set.ts`。

`figure` 收到的是卡片上的原点坐标，返回相对该原点的图元；坐标一律写绝对值
（见 [TOOLS.md](./TOOLS.md) 的坐标约定）。**新图形请一并在
`src/__tests__/figures.test.ts` 里加验算**，否则没人能发现它画歪了。

## 导入真实试卷

想用真实扫描件做转录核对时：

1. PDF 放进 `.work/pdf/`
2. 在 `.work/crops.json` 里加 `{id, pdf, page, y, h}`，跑 `node .work/recrop.mjs` 按题裁图
3. 把 `Problem.image` 指向裁出的文件，`statement` 填人工转录的题干

注意版权：他人编纂的试卷汇编不要连内容一起提交到公开仓库。
