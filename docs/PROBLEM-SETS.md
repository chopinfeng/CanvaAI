# 题目导入与转换核对

## 为什么要"原图 + 转换结果"并排

题目从扫描件进画布，中间隔着一次转录。**转录对不对，只能靠对照原件判断**——
所以每道题左边放从 PDF 直接裁下来的原图，右边放转换后的画板内容。
不需要相信转换过程，看一眼就知道。

## 数据来源

两份公开的中考复习汇编（扫描件，无文字层）：

- `2023 年中考数学复习探究性试题汇编之相似三角形`（63 页，15 题）
- `2023 年中考数学复习探究性试题汇编之三角形`（54 页，15 题）

从中取 20 道，覆盖：折叠、旋转、手拉手模型、动点函数、二次函数、内心外接圆、
角平分线、共顶点等腰、八字模型等。

## 转换到什么程度

| 部分 | 覆盖 | 说明 |
|---|---|---|
| 题干文字 | 20/20 | 条件 + 各小问要求，逐题转录 |
| 已知量结构化 | 8/20 | `known` 字段，Agent 可直接查，不用从文本里再抠 |
| 矢量化图形 | 13/20 | 见下面的取舍标准 |
| 原图 | 20/20 | 全部保留 |

## 矢量化的取舍标准

**只有坐标能由题给条件精确算出来的，才矢量化。**

理由不是省事：Agent 会用 `canvas_measure` 去量图上的线段和角度，然后拿量出来的数推理。
凭感觉摆出来的图，量出来的每个数都是错的——**那比没有图更糟**。

按这个标准，20 道里 13 道能画、7 道不能：

| 不画 | 原因 |
|---|---|
| S5 | E 在 BC 延长线上位置自由，F、G 跟着跑；第 (2) 问用 FG=1、FA=3 才钉住 |
| S9 | E 在 CD 上自由；"D′ 与 F 重合"是结论不是条件，画出来等于给答案 |
| S10 | D 在外角平分线上位置自由，AE/CD 是定值但边长不是 |
| T4 | 两个等腰三角形绕公共顶点的相对转角自由 |
| T5 | 三问构形各不相同且都依赖自由动点，只画个等边三角形没有增量信息 |
| T6 | 需先选定一个具体 △ABC 才能作外接圆与内心，题目没给 |
| T7 | ∠EAF 大小与 P 的位置都自由 |

这些原因也写在画布上，免得看的人以为是漏了。

### 已矢量化的 13 道

坐标推导写在 `scripts/figures.ts` 的注释里，并在 `src/__tests__/figures.test.ts` 里
按原题条件逐条复验——给定的长度、角度、平行、共线、中点关系，一条都不能对不上。

- **S3** B(5,0) 关于折痕 AE 的反射点精确落在 F(4,3)（有理数验算），EF=EB=5/3
- **S3 / S4 / S7 / T3 / T9** 第 (1) 问的答案（BE=5/3、CD=10、∠P=45°、AC=2√2、高=4）都能从图上量出来
- **T1** AE 取任何值，AD=BE 与 ∠BFD=60° 都成立，所以取一个具体值不误导，反而能量出来验证结论
- **T8** 由 C(0,−4)、D(2,−6) 解出 y=x²−3x−4，根为 −1 和 4，G(−2,6) 确在图象上

### 一个副作用

图按标准答案的位置画出来，意味着 Agent 量一下就能得到待求量。
辅导模式因此加了一条硬约束：测量只能用来检验学生自己算的结果、
或制造让他自己发现矛盾的事实，**量出来的答案不准说**。见 `TUTOR_ADDENDUM`。

## 图片资源

内容哈希命名（`as_<sha256前24位>.<ext>`），所以：

- 同一张图重复上传只占一份
- **重新上传能得到完全相同的 id** —— 资源丢了重灌一遍，画布里的引用不会断

存放在 `<仓库根>/data/assets/`，通过 `GET /assets/:id` 提供，长缓存。
id 有严格格式校验，挡掉路径穿越。

## 加自己的题

1. 把 PDF 放进 `.work/pdf/`
2. 在 `.work/crops.json` 里加一条 `{id, pdf, page, y, h, src}`，重跑裁剪
3. 在 `apps/server/scripts/problems.ts` 里加一条 `Problem`：转录题干，
   图形简单就给 `figure`，复杂就留空
4. 重跑 seed 脚本

`figure` 收到的是卡片上的原点坐标，返回相对该原点的图元；坐标一律写绝对值
（见 [TOOLS.md](./TOOLS.md) 的坐标约定）。
