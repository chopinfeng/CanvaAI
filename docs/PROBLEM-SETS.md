# 题目导入与转换核对

## 为什么要"原图 + 转换结果"并排

题目从扫描件进画布，中间隔着一次转录。**转录对不对，只能靠对照原件判断**——
所以每道题左边放从 PDF 直接裁下来的原图，右边放转换后的画板内容。
不需要相信转换过程，看一眼就知道。

## 数据来源

两份公开的中考复习汇编（扫描件，无文字层）：

- `2023 年中考数学复习探究性试题汇编之相似三角形`（63 页，15 题）
- `2023 年中考数学复习探究性试题汇编之三角形`（54 页，15 题）

从中取 20 道，覆盖：折叠、旋转、手拉手模型、动点函数、二次函数、内心外接圆、
角平分线、共顶点等腰、八字模型等。

## 流水线

```
PDF ──pdftoppm──▶ 整页 PNG ──按题裁剪──▶ 原图 ──POST /assets──▶ assetId
                                            │
                        视觉转录（题干 / 已知量 / 图形）
                                            ▼
                              problems.ts ──seed 脚本──▶ 画布
```

裁剪坐标在 `.work/crops.json`，逐题标了页码和 y 范围。改动后重跑即可。

```bash
node .work/recrop.mjs           # 重新裁剪（坐标改了之后）
```

```bash
cd apps/server && npx tsx scripts/seed-exam-set.ts exam-set
```

只灌指定几题：

```bash
cd apps/server && npx tsx scripts/seed-exam-set.ts drill S3 T8
```

## 转换到什么程度

| 部分 | 覆盖 | 说明 |
|---|---|---|
| 题干文字 | 20/20 | 条件 + 各小问要求，逐题转录 |
| 已知量结构化 | 8/20 | `known` 字段，Agent 可直接查，不用从文本里再抠 |
| 矢量化图形 | 3/20 | 仅 S3、S6、T8 |
| 原图 | 20/20 | 全部保留 |

**为什么只矢量化 3 道。** 这些压轴题大多配三联图（图1/图2/图3 表示动点的不同位置），
手工还原既费时又容易走样。**画一个走样的图比不画更糟**——Agent 会拿它当真去测量推理。
所以只在能忠实还原时才矢量化，其余以原图为准，`problems.ts` 里会明确标注。

已矢量化的三道，几何量都经过验算：

- **S3** 矩形折叠：B(5,0) 关于折痕 AE 的反射点精确落在 F(4,3)，有理数验算
- **S6** Rt△ABC：∠A=90°、AB=2、tanC=1/2 ⇒ AC=4
- **T8** 抛物线：由 C(0,−4)、D(2,−6) 解出 y=x²−3x−4，根为 −1 和 4；G(−2,6) 确在图象上

## 图片资源

内容哈希命名（`as_<sha256前24位>.<ext>`），所以：

- 同一张图重复上传只占一份
- **重新上传能得到完全相同的 id** —— 资源丢了重灌一遍，画布里的引用不会断

存放在 `<仓库根>/data/assets/`，通过 `GET /assets/:id` 提供，长缓存。
id 有严格格式校验，挡掉路径穿越。

## 加自己的题

1. 把 PDF 放进 `.work/pdf/`
2. 在 `.work/crops.json` 里加一条 `{id, pdf, page, y, h, src}`，重跑裁剪
3. 在 `apps/server/scripts/problems.ts` 里加一条 `Problem`：转录题干，
   图形简单就给 `figure`，复杂就留空
4. 重跑 seed 脚本

`figure` 收到的是卡片上的原点坐标，返回相对该原点的图元；坐标一律写绝对值
（见 [TOOLS.md](./TOOLS.md) 的坐标约定）。
